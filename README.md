# Pong Recompiled

A PC rebuild of Pong: The Next Level (PS1), with rollback netplay through
[Soggy Pigeon](https://github.com/BrendleFly/Soggy-Pigeon).

## Download

Grab the installer from [Releases](https://github.com/BrendleFly/Pong-The-Next-Level-Decomp/releases).
The installer verifies your own legally made disc copy of the game (it is
referenced, never copied or distributed). The zip ships the same build
without the installer.

## Source

The source code is not published here. This repository carries releases only.
